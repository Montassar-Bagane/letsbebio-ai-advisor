\section*{Appendix 1 --- Controlled vocabularies}

\textbf{Customer concerns} (25 values).
\emph{Skin:} taches\_pigmentaires, rides\_age, deshydratation,
imperfections\_acne, rougeurs\_sensibilite, exces\_sebum, eclat\_teint,
protection\_solaire, cernes\_poches, pores\_dilates, hygiene.
\emph{Hair:} chute\_cheveux, pellicules, cheveux\_abimes.
\emph{Internal:} digestion, immunite, sommeil\_stress, energie\_tonus,
articulations, memoire\_concentration, glycemie\_tension, fertilite,
sport\_nutrition, minceur\_detox, cheveux\_peau\_ongles.
Plus \texttt{aucun} for products making no health or beauty claim.

\medskip
\textbf{Skin types.} normale, seche, mixte, grasse, sensible, acneique, mature,
tous.

\medskip
\textbf{Hair types.} secs, gras, normaux, abimes, colores, boucles\_frises,
pellicules, chute, tous.

\medskip
\textbf{Application zones.} visage, yeux, levres, mains, pieds, bouche, cheveux,
corps, oral, maison, polyvalent.

\medskip
\textbf{Routine steps.} nettoyage, tonification, traitement, hydratation,
protection, soin\_cible, complement\_oral, non\_applicable.

\section*{Appendix 5 --- Deployment configuration}

Environment variables required by the service:

\begin{lstlisting}[language=]
CLIENT_NAME=letsbebio

DB_HOST=127.0.0.1
DB_USER=reco_read          # SELECT privilege only
DB_PASSWORD=...
DB_NAME=wordpress
WP_PREFIX=wp_11e347_       # specific to each installation

SITE_URL=https://example.tn
CORS_ORIGINS=https://example.tn

REBUILD_MINUTES=60
LIVE_STOCK=true
ADMIN_TOKEN=...
RATE_LIMIT_PER_MIN=60

ENABLE_INTERPRET=true
LLM_BASE_URL=https://api.groq.com/openai/v1
LLM_API_KEY=...
LLM_MODEL=llama-3.3-70b-versatile
\end{lstlisting}

Creation of the read-only database user:

\begin{lstlisting}[language=]
CREATE USER 'reco_read'@'%' IDENTIFIED BY '...';
GRANT SELECT ON wordpress.* TO 'reco_read'@'%';
FLUSH PRIVILEGES;
\end{lstlisting}
